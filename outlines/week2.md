# 31 Days of Vibe Coding – Week 2: Advanced Vibe Coding Techniques (Days 8–15)

**Theme:** Mastering the practice of AI-assisted development: prompting, configuration, context management, and iteration.

---

## Day 8 – Advanced Prompting Patterns

**Abstract:**
You know basic prompts. Time to level up. Learn advanced prompting techniques: chain-of-thought for complex logic, few-shot examples for consistency, constraints for security, and prompt templates you can reuse. Turn prompting into a skill.

**What You'll Learn:**
- Chain-of-thought prompting for complex tasks
- Few-shot examples to teach patterns
- Adding constraints (security, performance, style)
- Prompt templates for common tasks
- Breaking large tasks into smaller prompts
- When to be specific vs let AI decide
- Example: Building a complete feature with advanced prompts

---

## Day 9 – AGENTS.md and CLAUDE.md: Configuring Your AI Partner

**Abstract:**
Stop repeating yourself in every prompt. Learn to configure AI agents with AGENTS.md and CLAUDE.md files: defining coding standards, specifying frameworks, embedding security requirements, and setting observability expectations. Make AI generate code that fits your style from the start.

**What You'll Learn:**
- What goes in AGENTS.md vs CLAUDE.md
- Defining coding standards and conventions
- Specifying your tech stack and frameworks
- Embedding security and observability requirements
- Examples and anti-patterns
- Testing your agent configuration
- Example: Complete agent config for your stack

---

## Day 10 – Vibe Coding Commandments: Rules to Code By

**Abstract:**
After a week of building with AI, let's codify the rules. These are the non-negotiables: principles that separate confident vibe coders from those just hoping AI gets it right. Print this, pin it, tattoo it. These commandments will keep you shipping fast without breaking production.

**What You'll Learn:**
- Plan features, not functions
- Tests are your specification, not documentation
- Observability is proof, not optional
- Automate verification, don't manually review
- Every deployment must be reversible
- Security is automated or it doesn't exist
- Trust the AI, verify everything
- Stay in flow, ship with confidence
- When to override the AI
- The viral-ready checklist

---

## Day 11 – Context Management and Long Sessions

**Abstract:**
AI forgets. Long coding sessions lose context. Learn to manage context effectively: what to include in prompts, when to start fresh, how to maintain continuity, and strategies for multi-day projects. Keep AI aligned with your goals across long sessions.

**What You'll Learn:**
- What AI needs in context (and what's noise)
- Including relevant code snippets
- When to start a new conversation
- Maintaining consistency across sessions
- Using files vs inline context
- Context limits and how to work with them
- Example: Building a feature over multiple days

---

## Day 12 – Teaching AI Your Style and Patterns

**Abstract:**
AI writes generic code. You have a style. Learn to teach AI your patterns: providing examples, establishing naming conventions, defining your architecture patterns, and building a style guide AI can follow. Make AI code feel like your code.

**What You'll Learn:**
- Providing example code for AI to follow
- Establishing naming conventions
- Teaching your architecture patterns
- Building a reusable style guide
- Using existing code as templates
- Correcting AI when it diverges from your style
- Example: Creating your personal coding style guide

---

## Day 13 – Iterative Development Loops

**Abstract:**
Vibe coding isn't one-and-done. It's iterative. Learn the rhythm: prompt, evaluate, refine, repeat. Master short feedback loops, knowing when to iterate vs start over, and using AI's output as input for the next iteration. Find your flow.

**What You'll Learn:**
- The prompt-evaluate-refine loop
- Short iterations vs big changes
- When to iterate vs start fresh
- Using AI's output as the next prompt
- Maintaining momentum in flow
- Knowing when you're done
- Example: Building a feature through iterations

---

## Day 14 – Multi-File and Multi-Turn Conversations

**Abstract:**
Real features span multiple files. Learn to coordinate AI across files: creating multiple related files, maintaining consistency, handling dependencies, and keeping architecture coherent. Build complete features, not just single files.

**What You'll Learn:**
- Planning multi-file features
- Creating related files in one session
- Maintaining consistency across files
- Handling imports and dependencies
- Architectural coherence across files
- When to split into separate conversations
- Example: Complete feature across 5+ files

---

## Day 15 – When to Use AI and When to Code Yourself

**Abstract:**
Not everything needs AI. Learn when AI accelerates you and when it slows you down. Recognize tasks perfect for AI, tasks better done manually, and the hybrid approach. Maximize your velocity by choosing the right tool for each task.

**What You'll Learn:**
- Tasks where AI excels (boilerplate, patterns, etc.)
- Tasks where you're faster (tiny tweaks, formatting)
- The hybrid approach (AI drafts, you refine)
- Recognizing diminishing returns
- When prompting takes longer than coding
- Building your intuition for AI vs manual
- Example: Decision matrix for AI usage

You've mastered advanced vibe coding techniques: sophisticated prompting patterns, agent configuration files, context management, teaching AI your style, iterative development, multi-file coordination, and knowing when to use AI vs code yourself. You're now a skilled AI-assisted developer.
