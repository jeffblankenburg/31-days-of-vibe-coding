# Prompt Library Starter Kit

A collection of reusable prompt templates for AI-assisted development. Part of the [31 Days of Vibe Coding](https://31daysofvibecoding.com) series.

## Structure

```
prompt-library/
├── generation/        # Creating new code
│   ├── feature.md
│   ├── api-endpoint.md
│   ├── component.md
│   └── test-suite.md
├── review/           # Auditing existing code
│   ├── security.md
│   ├── sre.md
│   ├── maintainability.md
│   └── edge-cases.md
├── debug/            # Finding and fixing problems
│   ├── investigate.md
│   ├── log-analysis.md
│   └── stack-trace.md
├── refactor/         # Improving existing code
│   ├── code-smells.md
│   ├── extract-function.md
│   └── naming.md
└── deploy/           # Shipping to production
    ├── migration.md
    ├── rollback.md
    └── checklist.md
```

## How to Use

1. Find the template that matches your task
2. Copy the template
3. Fill in the `{placeholders}` with your specifics
4. Use with your preferred AI tool

## Customizing

These templates are starting points. Customize them for your:
- Tech stack
- Coding standards
- Team conventions
- Project patterns

When you find improvements, update the templates. Your prompt library should evolve with your experience.
